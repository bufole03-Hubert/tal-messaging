# Politique de sécurité

## Versions prises en charge
Étant donné qu'il s'agit d'une plateforme axée sur la sécurité (authentification, 2FA TOTP, isolation multi-tenant), nous prenons les vulnérabilités très au sérieux.

| Version | Prise en charge |
| ------- | --------------- |
| `main`  | :white_check_mark: Oui |

## Signaler une vulnérabilité
Si vous découvrez une faille de sécurité (ex: contournement d'isolation des tenants, faille d'authentification, injection), **veuillez ne pas l'ouvrir publiquement dans une Issue**.

Préférez une signalisation privée ou contactez directement le mainteneur principal :
* **Email de contact** : Via le profil GitHub [lucien-amani](https://github.com/lucien-amani)
* Nous vous répondrons dans les plus brefs délais pour valider et corriger la vulnérabilité avant toute divulgation publique.
